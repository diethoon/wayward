Wayward Google Drive CloudSave — WML v0.5.2

설치
1. cloud-save 폴더를 게임의 wml/mods/ 안에 복사합니다.
2. wml/mods/mods.js의 WML.enable([...])에 "cloud-save"가 있는지 확인합니다. 없을 때만 기존 목록을 보존해 추가합니다.
3. 게임을 다시 열고 클라우드세이브 (Google Drive)를 엽니다.
4. Google 계정으로 연결을 누르고 GitHub Pages 인증 화면에서 계정과 Drive 앱 데이터 권한을 승인합니다.

인증 경로
- GitHub Pages: https://jeiky224.github.io/cloud/
- Cloudflare Worker: https://wayward-auth-relay.trpgengine1.workers.dev
- Google OAuth 리디렉션 URI: https://jeiky224.github.io/cloud/
- Worker Secret: GOOGLE_CLIENT_SECRET (Google Cloud Console의 해당 OAuth Client Secret을 Cloudflare Worker Secret으로 등록)
- Google Client Secret을 게임 파일, GitHub Pages 또는 저장소에 넣지 마세요.
- GitHub Pages는 jeiky224/cloud 저장소의 main 브랜치 루트에서 게시해야 합니다.

인증 동작
OAuth Authorization Code + PKCE, nonce 검증 postMessage 및 Cloudflare Worker WebSocket 릴레이를 사용합니다. 게임의 file://, localhost, 127.0.0.1, LAN HTTP, HTTPS, WebView Origin은 Google OAuth 등록 목록에 각각 추가할 필요가 없습니다. WebView가 팝업을 차단하면 모드가 표시하는 외부 브라우저 로그인 링크를 사용하세요. 이때 게임 화면을 닫지 않아야 임시 WebSocket 중계로 인증 결과가 돌아옵니다. 팝업과 WebSocket을 모두 막는 실행기는 지원되지 않습니다.

로그인 유지
"로그인 계속 유지"는 refresh token을 게임 Origin과 GitHub 인증 페이지의 공통 저장소에 보관합니다. localhost, 127.0.0.1, file:// 등 게임 주소가 달라도 같은 브라우저 프로필의 GitHub 인증 페이지가 저장된 refresh token으로 자동 로그인합니다. "새로고침하면 로그아웃"을 선택하면 게임 저장소와 인증 페이지 공통 저장소를 지웁니다. 로그아웃은 Google 권한 철회를 요청하고 양쪽 저장소의 로그인 정보를 삭제합니다.

브라우저 프로필이나 앱/WebView 데이터가 서로 분리되면 저장소도 분리되므로, 각 프로필에서는 최초 1회 인증해야 합니다. Google이 토큰을 취소하거나 OAuth 동의 화면이 Testing 상태이면 영구 유지가 보장되지 않습니다. Testing 상태의 외부 사용자 refresh token은 일반적으로 7일 후 만료되므로 OAuth 동의 화면은 Production으로 게시해야 합니다.

저장 파일은 게임 페이지에서 암호화한 뒤 Google Drive appDataFolder로 직접 업로드합니다. 인증 서버에는 게임 세이브 본문을 보내지 않습니다. 기존 Cloudflare 일회성 공유 저장 자료는 자동 이관되지 않습니다.
