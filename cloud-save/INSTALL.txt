Wayward Google Drive CloudSave — WML v0.6.0

설치
1. cloud-save 폴더를 게임의 wml/mods/ 안에 복사합니다.
2. wml/mods/mods.js의 WML.enable([...])에 "cloud-save"가 있는지 확인합니다. 없을 때만 기존 목록을 보존해 추가합니다.
3. 게임을 다시 열고 클라우드세이브 (Google Drive)를 엽니다.

인증
- 브라우저 인증 페이지: https://jeiky224.github.io/cloud/
- Google Identity Services Token Model 사용 (OAuth Client Secret, code exchange server, refresh-token server 없음)
- Google OAuth Web Client의 Authorized JavaScript origins에 https://jeiky224.github.io 등록
- Redirect URI / Client Secret 등록 불필요
- GitHub Pages 저장소 jeiky224/cloud의 main 루트에 index.html을 배포해야 합니다.
- 인증 페이지는 사용자 승인 후 액세스 토큰을 opener postMessage로 전달합니다. nonce, Referer origin, popup source/origin을 검증하며 토큰을 URL에 넣지 않습니다.
- 게임은 Google Drive API를 직접 호출합니다. Cloudflare Worker, Cloudflare Pages/Functions, Durable Objects, WebSocket relay, 개인 서버는 사용하지 않습니다.

Android 공식 런처
- Google은 OAuth 웹 로그인을 Android WebView 안에서 지원하지 않습니다.
- 공식 런처의 기존 Android Google Identity Authorization 브리지를 사용하여 액세스 토큰을 얻습니다.
- 해당 네이티브 브리지는 액세스 토큰을 WML에 돌려주며 외부 서버 중계를 사용하지 않습니다.
- 다른 WebView 런처는 동일한 네이티브 인증 API가 없으면 지원하지 않습니다.

로그인 유지 / 재인증
- 브라우저 Token Model은 Refresh Token을 발급하지 않습니다.
- 액세스 토큰은 현재 게임 탭의 메모리에만 저장됩니다. 만료 후에는 Google 계정으로 다시 연결해야 합니다.
- "로그인 계속 유지"는 동일 브라우저의 Google 계정 세션이 남아 있을 때 계정 선택을 간소화하는 설정일 뿐, 자동 갱신이나 영구 로그인을 의미하지 않습니다.
- v0.5.2에서 저장한 구형 Refresh Token은 이 버전이 로드될 때 삭제합니다.

로그아웃
- 로컬 액세스 토큰과 구형 저장 토큰을 삭제합니다.
- 일반 브라우저는 Google Identity Services revoke() 호출 성공 시 권한 철회 성공으로 표시합니다.
- Android 공식 런처는 로컬 Google Identity 토큰 캐시 삭제를 수행합니다. Google 서버의 앱 권한 철회는 별도 확인되지 않습니다.

지원 환경 제한
- 브라우저: localhost, 127.0.0.1, 0.0.0.0, 사설 LAN HTTP, HTTPS (실제 Referer Origin 일치 필요)
- file:// 브라우저 실행은 opaque origin 검증 불가로 지원하지 않습니다. 로컬 HTTP 서버 사용을 권장합니다.
- Android: Android Google Identity 브리지가 포함된 공식 Wayward Launcher 사용
- 팝업 차단 시 브라우저 사이트 설정에서 게임의 팝업을 허용해야 합니다.

세이브
- Google Drive appDataFolder에 직접 저장합니다.
- 파일 암호화, 슬롯 ID, 기존 저장 데이터 구조, 업로드/다운로드/복원 로직은 유지합니다.
- 자동 암호화의 내장 키는 공개 소스에서 추출 가능하므로 강한 보안을 보장하지 않습니다.
