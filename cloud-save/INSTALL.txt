Wayward Google Drive CloudSave — WML v0.7.1

설치
1. cloud-save 폴더 전체를 게임의 wml/mods/ 폴더에 복사합니다.
2. wml/mods/mods.js의 기존 WML.enable([...]) 배열에 "cloud-save"가 있는지 확인합니다. 없으면 기존 모드 ID를 보존하면서 추가합니다.
3. 게임을 다시 열고 클라우드세이브 (Google Drive)를 실행합니다.

구성 파일
- mod.js: WML.define({ id: 'cloud-save', version: '0.7.0', ... }) 메타데이터 및 게임↔정적 인증 페이지 postMessage bridge
- crypto.js: 기존 AES-256-GCM / embedded-addon-v2 / PBKDF2 legacy 복호화
- README.md: 전체 아키텍처 및 저장 호환성 설명

Google OAuth 인증과 모든 Google Drive API 요청은 https://jeiky224.github.io/cloud/auth.html 정적 HTTPS 페이지에서만 실행됩니다.
게임 모드에는 access token이 전달되지 않습니다. 토큰 복사/붙여넣기 수동 우회도 제공하지 않습니다.
