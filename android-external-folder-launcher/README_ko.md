# Wayward Android Launcher 0.3.12 · ImageGen 상태 관리 빌드

Android SAF 폴더 실행기입니다. 게임 원본 폴더를 직접 읽고, 각 등록 게임을 독립된 WebView 세션으로 실행합니다. Image Studio 백엔드는 현재 선택한 게임 세션의 `wml/mods/imagestudio/backend`에서만 감지하며, 런처 공용 서버 하나를 `127.0.0.1:8189`로 실행합니다.

## 1. 게임 폴더와 세션

1. **게임 폴더 추가**에서 Wayward 또는 Faith 게임 폴더를 등록합니다.
2. 등록 목록의 **실행**을 누르면 해당 폴더만 독립 세션으로 열립니다.
3. Android 최근 앱 화면에서 등록한 세션을 전환할 수 있습니다.

게임 폴더는 SAF 권한으로 읽습니다. HTML, 이미지, WML 모드 파일을 원본 위치에서 읽으며 런처가 게임 폴더의 파일을 임의로 변경하지 않습니다. 세션별 WebView 저장소와 WML 모드 활성화/로드 순서는 각각 분리됩니다.

## 2. 모드 ZIP 선택

런처 홈에는 앱 전용 ZIP 저장소나 전역 모드 설치 메뉴가 없습니다. 모드 ZIP은 **게임 안의 WML 모드 관리자 → 모드 파일 고르기**를 사용해 선택합니다. Android SAF 파일 선택 결과를 해당 게임 WebView에 직접 전달하는 기본 파일 선택기만 유지합니다.

따라서 앱 전용 ZIP 목록, ZIP 제거 버튼, 다른 게임 세션에 공통으로 주입되는 모드 오버레이는 제공하지 않습니다. ZIP 설치와 활성화는 각 게임 세션의 WML 모드 관리 흐름을 사용합니다.

## 3. Image Studio 서버

- 게임 세션을 열 때 해당 세션의 `wml/mods/imagestudio/mod.js`와 backend 엔트리(`package.json`, `src/cli.ts`)를 확인합니다.
- 백엔드가 있으면 런처 내부 Bun 런타임과 ImageGen 서비스를 자동으로 준비한 뒤 게임 WebView를 엽니다. Image Studio가 없거나 준비에 실패해도 게임은 열립니다.
- 여러 세션은 동일한 백엔드 버전을 사용할 때 런처 공용 서버를 공유합니다. 버전이 다르면 잘못된 백엔드 연결을 막습니다.
- 런처 홈에서 **서버 시작**, **재시작**, **서버 중지**를 수동으로 실행할 수 있습니다. 서버 시작 시 게임 폴더를 선택하며, 현재 활성 세션이 Image Studio를 포함하면 해당 세션을 우선 사용합니다.
- 서버 상태는 2초 간격으로 `http://127.0.0.1:8189/api/image/health`를 확인합니다. 서비스 heartbeat와 Health API 응답을 별도로 표시하므로 프로세스 상태가 stale하거나 API 응답이 끊긴 상태를 정상으로 표시하지 않습니다.
- Android 알림에서도 서버 중지를 실행할 수 있습니다. 서버가 실행 중일 때는 알림을 유지합니다.

Bun Android ARM64 v1.4.4 실행 파일은 공식 아카이브를 내려받아 SHA-256 검증 후 설치합니다. 진단 로그는 앱 비공개 저장소에 기록합니다. 로그 수집 시 게임 세이브, 이미지, 프롬프트, 요청/응답 본문, 인증 헤더, 쿠키 및 API 토큰을 수집하지 않습니다.

## 4. 동료 모드

런처 내장 `launcher-mobile-companions` 및 **동료 모바일 실시간 창** 어댑터를 제거했습니다. 런처가 Companions 전용 패널이나 별도 모듈 등록을 강제로 추가하지 않습니다. Companions 기능은 게임에 설치한 원본 모드의 기본 동작을 사용합니다.

## 5. 테스트 패키지

- 버전: **0.3.12**
- versionCode: **17**
- debug application ID: `com.wayward.launcher.imagegen0312`

0.3.11 테스트 앱과 별도 설치할 수 있습니다. 패키지 ID가 달라 게임 폴더와 WebView 저장소를 새 앱에서 다시 등록해야 하며, 기존 앱의 IndexedDB/localStorage와 세이브 데이터는 자동 이전되지 않습니다. 기존 앱은 삭제하지 마세요.

## 6. 검증 범위

CI에서 Node 계약 테스트, Java 상태 저장 테스트, Android debug APK 컴파일 및 APK 서명 검증을 수행합니다. 실제 Galaxy S25 Ultra에서 서버 기동, Health API 실시간 모니터링, NovelAI 이미지 생성 요청과 결과 표시까지 수행한 것은 별도 기기 검증으로 구분합니다.
